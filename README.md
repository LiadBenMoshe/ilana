# אילנה — מטבח ברזילאי

אתר מסעדה למטבח ברזילאי. דף HTML אחד, בלי תלויות ובלי תמונות חיצוניות.

- **תפריט של 31 מנות** עם השם הברזילאי המקורי, תעתיק לעברית, תיאור ומחיר
- **סינון כפול** — לפי קטגוריה (סלגאדוס, עיקריות, תוספות, קינוחים, שתייה)
  ולפי אזור בברזיל, והשניים עובדים יחד
- **חיפוש חופשי** שמחפש בשם הפורטוגזי, בעברית, בתיאור ובשם האזור —
  אפשר לחפש גם רכיב, למשל "קוקוס" או "שעועית"
- **אזורי ברזיל** — כל מנה מתויגת לאזור שממנו היא באה, עם מקטע שמסביר
  במה כל אזור שונה: בהיה, מינס ז׳ראיס, ריו, הדרום, אמזונס וסאו פאולו
- **תיוג צמחוני**, ומספר המנות הצמחוניות בפס העליון נגזר מהנתונים ולא
  מוקלד, כדי שלא יתיישן כשמוסיפים או מסירים מנה

העיטורים הצמחיים הם SVG מוטבע, ולכן הדף עובד גם אופליין.

## מה אמיתי ומה לדוגמה

השמות הברזילאיים, תיאורי המנות והשיוך לאזורים הם אמיתיים ונכונים.

הכתובת, הטלפון, שעות הפתיחה, המחירים וסיפור הרקע הם **תוכן לדוגמה**
וצריך להחליף אותם בנתונים האמיתיים לפני שימוש עסקי. יש על זה הערה גם
בתחתית הדף עצמו.

## עריכת התפריט

כל התפריט יושב במערך `DISHES` בתוך `<script>`. כל מנה היא אובייקט:

```js
{c:"main", pt:"Moqueca de Peixe", he:"מוקקה דה פיישי", p:112, r:"bahia", v:1,
 d:"תיאור המנה"}
```

`c` קטגוריה, `pt` השם הפורטוגזי, `he` התעתיק, `p` מחיר בשקלים,
`r` מפתח האזור מתוך `REGIONS`, `v:1` מסמן צמחוני, `d` התיאור.
הספירות בשבבי הסינון ובפס העליון מתעדכנות לבד.
